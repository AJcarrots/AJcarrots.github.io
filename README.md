**Selected Data Set:** Adult Criminal Activity in California

During the 1960's sample data was collected from California Institutions Preston, Fricot, and the Northern California Youth Authority. Data pertaining above institutions were collected through California Bureau of Criminal Investigation and Identification, some from FBI, and California Bureau of Vital Statistics (National Institute of Justice, 2006). Using two datasets: background data and follow-up arrest history from each institution the government identifies the pattern of someone who will likely break the law again -- *chronic offender*.

This data set could potentially be useful for helping individuals with transitioning after release from institution. This could be done through transdiciplinary. Using identified patterns of behavior from this data set and adding factors such as environment, geolocation, and support systems, to reduce the number of individuals who are likely to break laws again.
